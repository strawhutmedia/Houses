# EquityScout

Scraping government house auctions into one nice, searchable, filterable list —
so the below-market deals scattered across six government sites show up in a
single feed. Focused on **California (LA metro)** and **Oregon (Portland metro)**.

## What's here

```
index.html      Landing page + the live, filterable deal feed
styles.css      Styles
app.js          Feed logic: filters, sort, equity scoring, deal modal
data.js         Curated sample listings (fallback / demo data)
scraper/        Node scraper that writes listings.json from real gov sources
listings.json   Generated by the scraper (git-ignored)
```

## Run the website

It's a static site — no build step. Serve the folder and open it:

```bash
python3 -m http.server 8000    # then visit http://localhost:8000
```

(Opening `index.html` directly with `file://` also works, but a local server
is needed for it to load live `listings.json`.)

- If `listings.json` exists (from the scraper), the feed shows **live data**.
- Otherwise it shows the **sample data** in `data.js` — the page is never empty.

## Refresh the data

```bash
node scraper/run.js            # pull all sources -> listings.json
```

See [`scraper/README.md`](scraper/README.md) for per-source status and how to
finish the remaining adapters. Short version: **GSA is live**; the biggest win
for cheap residential deals is a **Bid4Assets** county tax-deed adapter.
